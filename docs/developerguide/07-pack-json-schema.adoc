== Pack JSON Schema

Pack project files are plain JSON.
All keys that appear in `PackManager._EMPTY_PACK` are guaranteed to be present after a load.

[cols="1,1,3"]
|===
| Key | Type | Description

| `version`
| `int`
| File format version (currently 1)

| `game`
| `str`
| `"snapshot"`, `"lewdshores"`, or `"naughtynightmares"`

| `pack_type`
| `str`
| `"photos"`, `"lovelens"`, or `"events"`

| `title`
| `str`
| Display name shown in-game

| `id`
| `str`
| Pack identifier (lowercase, no spaces)

| `id_range`
| `str`
| Numeric ID range, e.g. `"110400-110499"`

| `special_category`
| `str`
| Category / theme label shown in-game

| `special_category_color`
| `str`
| Hex color for the category bubble

| `special_types`
| `list[str]`
| Raw `specialType` entries from `[Special Traits]` (e.g. `"\"Busted!\",busted,kinky"`); written back verbatim on export

| `special_colors`
| `list[str]`
| Raw `specialColor` entries from `[Special Traits]`; written back verbatim on export

| `passthrough_sections`
| `list[tuple[str, list[str]]]`
| Raw `(header_line, content_lines)` blocks for unrecognised ini sections preserved verbatim on export.

| `defaults_position`
| `str`
| Default photo position written to `[Defaults]` (e.g. `"upskirt"`)

| `defaults_type`
| `str`
| Default photo type written to `[Defaults]`

| `defaults_color`
| `str`
| Default photo color written to `[Defaults]`

| `event_type`
| `str`
| City event type: `"normal"` or `"explosion"`

| `photos`
| `list[dict]`
| Photo entries (see below)

| `overlays`
| `dict[str, list[str]]`
| Overlay slot key → list of file paths

| `textures`
| `dict[str, list[str]]`
| Texture slot key → list of file paths

| `texts`
| `dict[str, str]`
| Love Lens dialog text overrides

| `events`
| `list[dict]`
| City/Beach event backgrounds, overlays, dialog JSON entries, and pack-level custom sounds — see <<event-entry>>

| `cutscenes`
| `list[dict]`
| Cutscene sequences (list of frame paths + metadata)

| `love_lens_photos`
| `dict[str, list[str]]`
| Result photo slot key → list of file paths

| `love_lens`
| `dict`
| Character setup: model, hairStyle, accessories, hairColor, eyeColor
|===

[[event-entry]]
=== Event Entry

Each dict in `events` has a `type` of `"background"`, `"overlay"`, `"dialog"`, or `"sound"`.

[cols="1,1,3"]
|===
| Key | Type | Description

| `type`
| `str`
| `"background"`, `"overlay"`, `"dialog"`, or `"sound"`

| `name`
| `str`
| Asset stem name used as the `pack.ini` key / exported Data filename (sound names never include their `.wav`/`.mp3` extension here — it is appended on export)

| `source`
| `str or None`
| Absolute path to the source image/video/audio file; `None` when imported by name only and not yet located on disk

| `content`
| `str`
| (`"dialog"` entries only) the flat `nd_*`/`pd_*` VIDE JSON, serialized as a string
|===

A `"sound"` entry is a pack-level custom WAV/MP3/OGG sound, added from the City/Beach Events tab's *Sounds* sub-tab (Snapshot!/Naughty Nightmares only — hidden for Lewd Shores). Its `name` is referenced from any dialog node's `playSound`/`playSoundDelayed`/`stopLoopedSound` command argument, alongside the pack's bundled game sounds.

=== Photo Entry

[cols="1,1,3"]
|===
| Key | Type | Description

| `name`
| `str`
| Internal image name (used as `pack.ini` key and `.dat` filename)

| `source`
| `str or null`
| Absolute path to the source image file.
During import the app tries `Data/<name>.dat`, then `Data/<name>.jpa`, `.pna`, `.png`, `.jpg`, `.jpeg`, then the same set in the pack root folder.
Images are identified by content (byte sniffing), not by file extension.

| `position`
| `str`
| Position value (e.g. `"upskirt"`, `"bench"`)

| `type`
| `str`
| Type value (e.g. `"plain"`, `"kinky"`)

| `color`
| `str`
| Color / special value (e.g. `"white"`, `"pink"`)

| `overwrite_type`
| `str`
| Custom display label for type (empty = use dropdown value)

| `overwrite_color`
| `str`
| Custom display label for color (empty = use dropdown value)

| `thumbnail`
| `bool`
| Whether this image is the pack thumbnail

| `hypnoType`
| `str`
| Love Lens scene sub-type (e.g. `"topless"`, `"nude"`); only written to ini when position is `hypno`

| `issue_flag`
| `bool`
| Set by the *Flag as Wrong…* dialog (Photos tab) when the photo is manually marked as wrongly defined; shown with a ⚠ marker in the photo list and listed in the Issue Report

| `issue_note`
| `str`
| Free-text description of what's wrong, entered in the *Flag as Wrong…* dialog; included in the Issue Report

| `issue_correction`
| `dict`
| `{"position": str, "type": str, "color": str}` — corrected values entered in the *Flag as Wrong…* dialog. When `issue_flag` is set, export (`_write_pack_ini`) writes these values instead of the photo's original `position`/`type`/`color`
|===
