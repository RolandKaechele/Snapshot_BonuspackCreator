== Environment Setup

[source,bat]
----
REM Create venv, install deps, open prompt
cli.bat
----

All Python commands use the venv explicitly:

[source,bat]
----
venv\Scripts\python.exe src\main.py
venv\Scripts\pytest tests\
----

Key dependencies:

[cols="1,3"]
|===
| Package | Purpose

| `PyQt6`
| All UI — widgets, signals, painting

| `Pillow`
| Image loading and dimension validation

| `configparser`
| Reading and writing `pack.ini` files

| `pytest` + `pytest-qt`
| Test suite and Qt widget testing

| `scons`
| Build system (`SConstruct`) for freezing and packaging

| `asciidoc`
| AsciiDoc Python library (pip); PDF output via `asciidoctor-pdf` (Ruby gem, separate)
|===
