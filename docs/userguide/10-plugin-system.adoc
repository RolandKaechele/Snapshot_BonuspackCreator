== Plugin System

Drop plugin packages or `.py` modules into the `plugins\` folder.
Each plugin must expose a `register(app)` function.
The application loads plugins automatically at startup.

See `plugins\README.md` for a minimal example.

=== Installing a Plugin

. Unzip (or copy) the plugin folder into `plugins\` so that it sits next to
  the existing plugin folders, e.g. `plugins\my_plugin\`.
. If the plugin ships a `requirements.txt`, install its extra dependencies
  into the application venv:
+
[source,bat]
----
venv\Scripts\python.exe -m pip install -r plugins\my_plugin\requirements.txt
----
. If the plugin needs local model/data files, follow its own `README.md` for
  where to place them (usually inside the plugin folder itself).
. Restart the application. Use *Tools → Manage Plugins…* to confirm the
  plugin loaded successfully; run with `--debug` for detailed load logs.
. Some plugins (e.g. diffusion backends for the AI Image Generator) only
  become active once their required files are present — the corresponding
  UI elements appear or hide automatically.

=== Enabling and Disabling Plugins

*Tools → Manage Plugins…* lists every plugin found in `plugins\` in a table, one row per plugin:

[cols="1,3"]
|===
| Column | Meaning

| Enabled
| Checkbox — unchecking disables the plugin; it is skipped on the next application start instead of being deleted from disk

| Name
| The plugin's package/module name (matches its folder name under `plugins\`)

| Version
| The plugin's `__version__` string, if it declares one (`—` otherwise)

| Status
| `Enabled`, `Disabled`, `Failed to load` (check `--debug` console output for the error), or `Unsupported Hardware` (the plugin declares a minimum VRAM requirement your GPU doesn't meet)

| Description
| The first line of the plugin's module docstring
|===

Re-check a disabled plugin (and restart) to re-enable it.
The choice is stored in `plugin_config.json` next to `registry.json`.

NOTE: Plugins marked *Unsupported Hardware* (e.g. `moss_image` on a GPU with less VRAM than it needs) have their checkbox greyed out and can't be checked — hover the row for the exact requirement and what was detected on your machine.
