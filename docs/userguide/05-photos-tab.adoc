== Photos Tab

The Photos tab is the main editing area for Regular Photos packs.

=== Adding Images

Click *Add…* and select one or more image files.
The app accepts `.png`, `.jpg`, `.jpeg`, and game-specific formats `.dat`, `.jpa`, and `.pna` (renamed JPEG / PNG files used by community packs).
Images are identified by their content, not by their file extension.

If a filename starts with `<position_value>_` (case-insensitive, e.g. `upskirt_00010.png`), the Position field is auto-preselected to match — otherwise the default position is kept.
Click *Naming Conventions…* in the toolbar to see every prefix → label mapping for the current game.

IMPORTANT: Regular photos and Love Lens result photos must be exactly 1024 × 1024 px.

=== Removing Images

Select one or more images in the list and click *Remove*.
All selected images are removed at once.

=== Filtering the List

Type into the *Filter* box above the photo list to narrow it down to images whose filename, position, type, color, or overwrite label contains the text (case-insensitive).
Clear the box (or click its ✕ button) to show every image again.

TIP: Adding new images or AI-generated images automatically clears the filter first, so the newly added images are visible and get selected correctly.

=== Selecting Multiple Images

The photo list supports multi-selection:

* Click a single item to select it.
* Hold *Ctrl* and click to add or remove individual items from the selection.
* Hold *Shift* and click to extend the selection to a range.

When multiple images are selected the detail panel shows the traits of the *first* selected image.
Changing Position, Type, Color/Special, Overwrite Type, or Overwrite Color/Special applies to *all* selected images at once.

NOTE: *Use as Thumbnail* is disabled while more than one image is selected — it can only be set for a single image.

=== Adjusting the List Display Size

Use the *Size* drop-down in the toolbar to change how large the image cards appear in the list:

[cols="1,2"]
|===
| Setting | Description

| Standard
| Compact text list (48 px icons)

| Large
| Icon grid with 80 px thumbnails

| Very Large
| Icon grid with 120 px thumbnails
|===

=== Assigning Traits

Each image has:

[cols="1,3"]
|===
| Field | Purpose

| Position
| Where in the game this photo appears (upskirt, bench, photoBooth, event, hypno, etc.)

| Type
| The underwear / content type (plain, kinky, cum, etc.)

| Color / Special
| The color tag or special detail shown in the photo detail view

| Love Lens Type
| Sub-type for Love Lens scenes (topless, nude, cumFace, etc.) — only visible when Position is set to `hypno`
|===

TIP: Position, Type, and Color/Special are editable drop-downs — type a custom value (e.g. a `[Special Traits]` alias token like `ghostHands` or `monster-cock-attack`) if it isn't already in the list; it's kept and exported verbatim instead of being replaced by the first list entry.

NOTE: Naughty Nightmares uses its own suggested Position/Type/Color vocabulary (e.g. `ghostHands`, `demon`, `werewolves`) instead of the base Snapshot! lists shown for Snapshot!/Lewd Shores.

Enable *Overwrite Type* or *Overwrite Color/Special* to replace the displayed label without changing the internal value.

Mark *Use as Thumbnail* on exactly one image to set the pack preview icon.

NOTE: `Position` values that only make sense for a different Pack Type — `City Event Photo` and `Love Lens Photo` — are hidden from the dropdown unless that Pack Type (*Events* / *Love Lens*) is currently active. If a photo imported from elsewhere already uses one of those positions while the pack's Pack Type doesn't match, its entry in the list is marked with a \u26a0 icon and a tooltip explaining the mismatch; see xref:10c-issue-report.adoc[Issue Report].

=== Flagging a Photo as Wrong

If a photo's Position, Type, or Color is wrong but you want to record the correct values for a bug report instead of (or in addition to) fixing it immediately, select the photo and click *Flag as Wrong…* in the toolbar.

The dialog lets you:

* Check *This photo is wrongly defined* to flag it.
* Enter the corrected Position, Type, and Color/Special.
* Add a free-text note describing the problem.

Flagged photos show a \u26a0 icon in the list. On export, the pack's `pack.ini` is written with the *corrected* values instead of the original ones — the original values stay in the project file so the issue remains visible and reportable. See xref:10c-issue-report.adoc[Issue Report] to generate a Markdown summary of every flagged photo.

=== Preview

The right panel shows a scaled preview of the selected image.
When multiple images are selected no preview is shown.

TIP: Double-click the preview to open a full-resolution viewer where you can zoom in/out (buttons or Ctrl+Scroll) and open the file in the system default editor.

=== Preprocessing Images

Click *Preprocess…* to resize and/or recompress image files already in the pack, directly on disk.
If one or more photos are selected, only those are processed; otherwise every photo in the pack is processed.

You will be asked for:

[cols="1,3"]
|===
| Setting | Meaning

| Max width / Max height
| Images larger than this (in pixels) are downscaled to fit, preserving aspect ratio. Use `0` for no limit. Images are never upscaled.

| JPEG/PNG quality
| Recompression quality (1–100). Use `100` to skip recompression when no resize is needed.
|===

WARNING: This modifies the image files on disk in place and cannot be undone — confirm you have originals backed up elsewhere if you need them unmodified.

=== Generating Images with AI

Click *AI Generate…* to open the AI image generator, which calls the https://perchance.org[perchance.org] text-to-image service (internet connection required).

==== Dialog Controls

[cols="1,3"]
|===
| Control | Purpose

| Position
| The game position the generated images will be tagged with (upskirt, bench, event, etc.)

| Photo Type
| The content-type modifier applied to the prompt (plain, kinky, nude, etc. for Snapshot!; front view, butt view, etc. for Lewd Shores).
  Select *(any)* to generate images for every type automatically.

| Base Prompt
| Describe your character — e.g. `anime girl, black hair, school uniform`

| Prompt Enhancement
| Pre-filled from the selected position; extend freely to add extra details

| Number of Images
| Slider 1–16 — how many images to generate *per prompt*

| Generate n images (current type)
| Generate for the selected position only.
  If Photo Type is *(any)*, generates n images for each modifier type.

| Generate n × types (all types from table)
| Generate for every position in the table.
  If Photo Type is *(any)*, generates n images for every position × modifier combination.
|===

NOTE: Large runs (e.g. *(any)* × all positions) can take several minutes.
A 1.5-second pause is inserted between requests to avoid rate-limiting, and the session is refreshed automatically if it expires mid-run.

==== Browser Verification (Cloudflare Turnstile)

perchance.org uses Cloudflare Turnstile to block non-browser clients.
The first time you generate images (or after a session expires), the app will:

1. Open `https://image-generation.perchance.org/embed` in your default browser.
2. Show a *Browser Verification* dialog with step-by-step instructions.

In the browser:

1. Press *F12* → click the *Console* tab.
2. If Chrome warns about pasting, type `allow pasting` and press Enter first.
3. Paste the command shown in the dialog and press Enter.
4. Copy the result (starts with `{"uk":…`) back into the dialog's text box.
5. Click *Verify*.

The dialog stays open until you verify or cancel.
Once verified, generation continues automatically.

==== Picking Images

After generation finishes a *Select AI-Generated Images* picker opens showing thumbnails of all generated images.
Select the images you want to keep (all are pre-selected) and click *OK*.

Only the selected images are added to the pack and moved into the pack folder.
Rejected images remain in the system temp folder and are not copied.

Each added image is automatically tagged with the Position and Photo Type used to generate it, which are shown immediately in the Image Properties panel.
