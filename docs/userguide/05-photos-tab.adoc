== Photos Tab

The Photos tab is the main editing area for Regular Photos packs.

=== Adding Images

Click *Add…* and select one or more image files.
The app accepts `.png`, `.jpg`, `.jpeg`, and game-specific formats `.dat`, `.jpa`, and `.pna` (renamed JPEG / PNG files used by community packs).
Images are identified by their content, not by their file extension.

IMPORTANT: Regular photos and Love Lens result photos must be exactly 1024 × 1024 px.

=== Removing Images

Select one or more images in the list and click *Remove*.
All selected images are removed at once.

=== Selecting Multiple Images

The photo list supports multi-selection:

* Click a single item to select it.
* Hold *Ctrl* and click to add or remove individual items from the selection.
* Hold *Shift* and click to extend the selection to a range.

When multiple images are selected the detail panel shows the traits of the *first* selected image.
Changing Position, Type, Color/Special, Overwrite Type, or Overwrite Color/Special applies to *all* selected images at once.

NOTE: *Use as Thumbnail* is disabled while more than one image is selected — it can only be set for a single image.

=== Adjusting the List Display Size

Use the *Size* drop-down in the toolbar to change how large the image cards appear in the list:

[cols="1,2"]
|===
| Setting | Description

| Standard
| Compact text list (48 px icons)

| Large
| Icon grid with 80 px thumbnails

| Very Large
| Icon grid with 120 px thumbnails
|===

=== Assigning Traits

Each image has:

[cols="1,3"]
|===
| Field | Purpose

| Position
| Where in the game this photo appears (upskirt, bench, photoBooth, event, hypno, etc.)

| Type
| The underwear / content type (plain, kinky, cum, etc.)

| Color / Special
| The color tag or special detail shown in the photo detail view

| Love Lens Type
| Sub-type for Love Lens scenes (topless, nude, cumFace, etc.) — only visible when Position is set to `hypno`
|===

Enable *Overwrite Type* or *Overwrite Color/Special* to replace the displayed label without changing the internal value.

Mark *Use as Thumbnail* on exactly one image to set the pack preview icon.

=== Preview

The right panel shows a scaled preview of the selected image.
When multiple images are selected no preview is shown.

TIP: Double-click the preview to open a full-resolution viewer where you can zoom in/out (buttons or Ctrl+Scroll) and open the file in the system default editor.

=== Generating Images with AI

Click *AI Generate…* to open the AI image generator, which calls the https://perchance.org[perchance.org] text-to-image service (internet connection required).

==== Dialog Controls

[cols="1,3"]
|===
| Control | Purpose

| Position
| The game position the generated images will be tagged with (upskirt, bench, event, etc.)

| Photo Type
| The content-type modifier applied to the prompt (plain, kinky, nude, etc. for Snapshot!; front view, butt view, etc. for Lewd Shores).
  Select *(any)* to generate images for every type automatically.

| Base Prompt
| Describe your character — e.g. `anime girl, black hair, school uniform`

| Prompt Enhancement
| Pre-filled from the selected position; extend freely to add extra details

| Number of Images
| Slider 1–16 — how many images to generate *per prompt*

| Generate n images (current type)
| Generate for the selected position only.
  If Photo Type is *(any)*, generates n images for each modifier type.

| Generate n × types (all types from table)
| Generate for every position in the table.
  If Photo Type is *(any)*, generates n images for every position × modifier combination.
|===

NOTE: Large runs (e.g. *(any)* × all positions) can take several minutes.
A 1.5-second pause is inserted between requests to avoid rate-limiting, and the session is refreshed automatically if it expires mid-run.

==== Picking Images

After generation finishes a *Select AI-Generated Images* picker opens showing thumbnails of all generated images.
Select the images you want to keep (all are pre-selected) and click *OK*.

Only the selected images are added to the pack and moved into the pack folder.
Rejected images remain in the system temp folder and are not copied.

Each added image is automatically tagged with the Position and Photo Type used to generate it, which are shown immediately in the Image Properties panel.
