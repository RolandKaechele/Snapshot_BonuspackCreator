== Installation

=== Requirements

* Windows 10 or later
* No Python or Java installation required — a portable Python runtime is bundled in `temp\`
* Optional: an NVIDIA GPU for faster *AI Generate…* image generation with local diffusion plugins (CUDA 12.8). Without one, those plugins fall back to CPU automatically — no extra setup needed.

=== First Run

. Double-click `cli.bat`.
  It will create a virtual environment in `venv\`, install all dependencies, and open a command prompt.
. From that prompt, launch the application:

[source,bat]
----
venv\Scripts\python.exe src\main.py
----

To enable verbose debug logging, add `--debug`:

[source,bat]
----
venv\Scripts\python.exe src\main.py --debug
----

=== Running the Frozen (Installed) App

If you received a self-extracting installer (`SnapshotPackCreator_vYYYY-MM-DD_cu128_installer.exe`) instead of the source checkout, no Python setup is needed — the app is already frozen into a standalone bundle.
Run the installer, pick a destination folder, and it extracts the following layout:

[source]
----
SnapshotPackCreator\
├── SnapshotPackCreator.exe   ← double-click to launch
├── _internal\
│   └── assets\               ← built-in game assets (Texture2D, AudioClip, blueprints)
├── plugins\                  ← empty by default; drop plugin folders here
└── docs\
    ├── userguide.pdf
    ├── developerguide.pdf
    └── plugin-developerguide.pdf
----

To enable debug logging in a frozen build, launch it from a command prompt with `--debug`:

[source,bat]
----
SnapshotPackCreator.exe --debug
----

=== First Launch of the Frozen App: PyTorch Setup

To keep the installer download small, PyTorch (used by local AI diffusion
plugins, ~2-3 GB) is *not* bundled — it is installed automatically the first
time you launch `SnapshotPackCreator.exe`. A progress dialog shows the
download; an NVIDIA GPU is detected automatically and the matching CUDA
build is installed, otherwise a CPU-only build is used.

This requires an internet connection on first launch. If it fails or you
click *Skip*, the app still starts normally — only the *AI Generate…*
buttons remain unavailable until PyTorch is installed (relaunch the app to
retry). After a successful install (or missing plugin dependency install),
the app automatically restarts itself once so the newly installed packages
load cleanly.

NOTE: Everywhere else in this guide, paths like `plugins\` or the assets folder are relative to `src\` in a source checkout, or relative to `SnapshotPackCreator.exe` in a frozen install — *Tools → Manage Plugins…* and *Tools → Open Asset Folder…* always open the correct one for however you're running the app.
