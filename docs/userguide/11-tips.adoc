== Tips and Common Mistakes

* *ID Range conflicts* — request a unique range on the Snapshot Discord before publishing. Two packs sharing the same range overwrite each other in-game.
* *Image size* — regular photos and Love Lens result photos must be exactly 1024 × 1024 px.
* *Large packs* — when exporting more than 100 photos the app automatically splits the pack into numbered ini files (e.g. `mypack1.ini`, `mypack2.ini`) and shifts the ID range by 100 per file, matching the format used by community mega-packs. If the ID Range you set is already wide enough to cover every photo (e.g. `200100-200299` for 104 photos), the pack is kept as a single `pack.ini` with that range instead of being split.
* *Bundle import* — packs with multiple ini files (no `pack.ini`) are imported by merging all files; part-number suffixes are stripped from the id and title automatically.
* *Game image formats* — `.dat`, `.jpa`, and `.pna` files (renamed JPEG / PNG) are supported on import and preview; images are identified by content, not extension.
* *Thumbnail* — set exactly one image as the thumbnail; it becomes the pack preview icon.
* *Overwrite text* — start with a capital letter to match the game's display style.
* *Changing game type* — switching between Snapshot!, Lewd Shores, and Naughty Nightmares resets all loaded images and settings; export your pack first.
* *Error dialogs* — every warning and error dialog has a *Copy to Clipboard* button so you can paste the full message when asking for support.
* *Undo/Redo* — Ctrl+Z/Ctrl+Y undo and redo recent edits across Photos, Events, Love Lens, and the Dialog Graph within the current session; history is cleared on New Pack/Open/Import.
* *Lost your changes?* — every *Save* also writes a timestamped backup to a `.backups\` folder beside the pack file; use *File → Restore Previous Version…* to recover one.
* *Sharing a pack* — use *File → Export Bonus Content as ZIP…* to get a single file matching the official pack layout (with a per-game `README.txt` and a checksum `manifest.json`) that's ready to upload or share directly.
