== Overwrite Texts Tab

=== Love Lens Dialog Texts

This tab is a key/value editor for the `[Hypnosis Text]` dialogue section.
Click *Add…* and enter a key (e.g. `hypno_start_mod.0`), then select it in the list to edit its text.
Leave an entry's text blank — or don't add the key at all — to use the game's built-in default text.

=== Speaker Field

Selecting a text key shows a paired *Speaker* field (backed by a `key.tag=` line in the ini).
Enter a character name to attribute the line to them, or leave it empty for narration.
Some keys (e.g. `hypno_start_mod.4`) are pre-filled with a sensible default speaker name the first time they're added.
