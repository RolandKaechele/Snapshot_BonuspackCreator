== Main Window

The main window is divided into:

* **Menu bar** — File, Edit, Tools, Help menus
* **Tab bar** — one tab per feature area
* **Status bar** — live feedback and validation messages

=== Menu Bar

[cols="1,3"]
|===
| Menu | Notable items

| File
| New/Open/Save/Save As; *Restore Previous Version…* (pick from the last 10 auto-backups); *Open Recent* (last 10 opened/saved packs); Import/Export Bonus Content; *Import Bonus Content from Archive…* (.zip/.rar); *Export Bonus Content as ZIP…*

| Edit
| *Undo* (Ctrl+Z) / *Redo* (Ctrl+Y); Settings…

| Tools
| Manage Plugins…; Edit AI Prompts…; *Find Duplicate Assets…*; *Compare Packs…*; *Pack Statistics…*

| Help
| About…
|===

Tabs that are not supported by the selected game are hidden automatically.
Choosing *Lewd Shores* hides Cutscenes and Love Lens, and relabels the City Events tab to *Beach Events* (shown when Pack Type = Events, same as Snapshot!). Choosing *Naughty Nightmares* hides City Events, Cutscenes, and Love Lens.
*Naughty Nightmares* additionally locks Pack Type to *Photos*, since Events and Love Lens packs are not supported for that game.
The tabs reappear/relabel instantly when you switch games.

== Tabs

[cols="1,2,1"]
|===
| Tab | Description | Game

| Pack Info
| Pack identity, defaults, special category and traits
| Both

| Photos
| Add and configure collectible photo cards
| Both

| Overwrite Texts
| Override displayed trait labels per image
| Both

| City Events
| Scripted events with dialog JSON and backgrounds; relabelled *Beach Events* for Lewd Shores, including two independent overlay layers (bottom + top)
| Snapshot!, Naughty Nightmares, Lewd Shores

| Cutscenes
| Frame-sequence cutscene preview and metadata
| Snapshot! only

| Love Lens
| Full character replacement set
| Snapshot! only

| Warnings
| Unreferenced assets on disk and broken ini references; auto-hidden when empty
| Both
|===
