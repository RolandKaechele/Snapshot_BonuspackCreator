== Packaging and Distribution

=== Recommended Package Structure

[source]
----
plugins\
└── my_awesome_plugin\
    ├── __init__.py        ← must contain register(app)
    ├── widget.py          ← optional sub-modules
    ├── tests\             ← optional; self-contained pytest suite (own conftest.py
    │                        adding src\ and plugins\ to sys.path — do not rely on
    │                        tests\pytests\conftest.py, which may not ship with
    │                        a standalone plugin distribution)
    └── README.md          ← describe what the plugin does
----

=== Dependencies

If your plugin requires third-party packages:

. List them in a `requirements.txt` inside your plugin folder.
. Document in your README that the user must install them. How depends on whether they're running from a source checkout or a frozen install:

[source,bat]
----
rem Source checkout — install into the application venv
venv\Scripts\python.exe -m pip install -r plugins\my_awesome_plugin\requirements.txt

rem Frozen install — use the bundled helper (no separate Python needed)
install_plugin_deps.bat plugins\my_awesome_plugin\requirements.txt
----

`install_plugin_deps.bat` ships next to `SnapshotPackCreator.exe` in every frozen build; it runs the bundled `tools\python\python.exe` (the exact Python 3.12 build used to freeze the app) to `pip install --target` the packages straight into `_internal\`, so only pure-Python packages or `cp312-win_amd64` wheels are safe to list.

Do not assume any package is available beyond what is already listed in the application's root `requirements.txt` (`PyQt6`, `Pillow`).

=== Distribution

Zip the plugin folder and share it.
Users drop the unzipped folder into `plugins\` and restart the application.

NOTE: `plugins\` already exists (empty) in a frozen install — `SConstruct` pre-creates it during the build since it's intentionally excluded from the PyInstaller bundle itself.

TIP: If you maintain your plugin inside this repo's own `plugins\` folder, `scons` does *not* build its SFX installer by default (to keep plain app builds fast) — run `scons plugins` (or `scons plugins=1` to also build the app) to produce it.

=== Versioning

Include a `__version__` string in your `__init__.py` for your own tracking:

[source,python]
----
__version__ = "1.0.0"

def register(app):
    ...
----
